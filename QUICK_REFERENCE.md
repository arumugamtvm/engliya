# Quick Reference Guide

## ✅ What's Fixed

### Speak Tab Scoring
- **Before**: Always 70-100% (too easy)
- **After**: Realistic 40-95% with progression
- **Result**: Challenging and motivating

### Lesson Content
- **Before**: Unclear standards

## 🎯 Key Numbers

### Speak Tab Scoring:
- First attempt: **40-75%** (learning)
- Second attempt: **50-85%** (improving)
- Third+ attempt: **60-95%** (mastering)

### Lesson Content Requirements:
- Explain: **400-600 words**
- Examples: **15+ sentences**
- Listen: **8+ exercises**
- Speak: **10+ exercises**
- Practice: **15+ questions**
- Mastery: **15+ questions**

### Passing Scores:
- Listen: **70%+** (6/8 correct)
- Speak: **70%+** average
- Practice: **60%+** (9/15 correct)
- Mastery: **80%+** (12/15 correct)

## 🚀 Quick Start

### To Run the App:
```bash
flutter pub get
flutter run -d <device-id>
```

### To Test Speak Tab:
1. Open any lesson
2. Go to Speak tab
3. Tap "Tap to Speak"
4. See realistic scoring
5. Practice to improve

### To Create New Lesson:
1. Read `COMPREHENSIVE_LESSON_GUIDE.md`
2. Follow the structure
3. Meet minimum requirements
4. Test with students
5. Iterate based on feedback
