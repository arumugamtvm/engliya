### 🚀 Getting Started

#### Quick Setup (3 Steps)

1. **Install Dependencies**
   ```bash
   flutter pub get
   ```

2. **Connect Real Device**
   - Speech recognition needs a real phone
   - Emulators/simulators won't work properly

3. **Run the App**
   ```bash
   flutter run
   ```
   Or use the helper script:
   ```bash
   ./RUN_APP.sh
   ```

#### First Time Use

1. Grant microphone permission when prompted
2. Open any lesson (e.g., "Subject Pronouns")
3. Navigate to the "Speak" tab
4. Tap "Tap to Speak" and try it out!

### 📊 Scoring System

- **90-100%**: Excellent! 🎉 Perfect pronunciation
- **70-89%**: Great job! 👍 Very good
- **50-69%**: Keep practicing! 💪 Getting there
- **Below 50%**: Try again! 📚 Need more practice

### 💡 Tips for Best Results

1. **Environment**: Find a quiet place
2. **Distance**: Hold phone 6-12 inches from mouth
3. **Pace**: Speak at normal, clear pace
4. **Pronunciation**: Focus on clear enunciation
5. **Practice**: Repeat sentences multiple times

### 🐛 Troubleshooting

#### "Speech recognition not available"
- Grant microphone permission in settings
- Use a real device (not simulator)
- Restart the app

#### "No speech detected"
- Speak louder and clearer
- Reduce background noise
- Check microphone not blocked

#### Low scores
- Speak at moderate pace
- Pronounce words clearly
- Practice in quiet environment
- Listen to example audio first
